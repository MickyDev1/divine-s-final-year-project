## Project Title

Computation and Plotting of Spectral Energy Density Using Planck's Radiation Law

## Project Aim

The aim of this project is to write and run a Python program that calculates
the spectral energy density of blackbody radiation using Planck's radiation
law, then plots the result for three different absolute temperatures:

- 3000 K
- 4000 K
- 5000 K

The final output is a graph of spectral energy density against wavelength.

## Given Equation

The spectral energy density equation used in this project is:

```text
u(lambda, T) = (8*pi*h*c / lambda^5) * 1 / (exp(h*c / (lambda*k_B*T)) - 1)
```

Where:

- `u(lambda, T)` is the spectral energy density.
- `lambda` is the wavelength.
- `T` is the absolute temperature in kelvin.
- `h` is Planck's constant.
- `c` is the speed of light.
- `k_B` is Boltzmann's constant.

## Explanation of the Python Code

### 1. Importing Required Libraries

```python
from pathlib import Path

import matplotlib.pyplot as plt
import numpy as np
from numpy.typing import NDArray
```

These imports allow the script to:

- work with file paths using `Path`
- perform numerical calculations using NumPy
- create graphs using Matplotlib

### 2. Defining Physical Constants

```python
PLANCK_CONSTANT = 6.62607015e-34
SPEED_OF_LIGHT = 2.99792458e8
BOLTZMANN_CONSTANT = 1.380649e-23
```

These constants are written in SI units:

- Planck's constant is in joule seconds
- speed of light is in meters per second
- Boltzmann's constant is in joules per kelvin

Using SI units is important because the formula is evaluated using meters,
kelvin, joules, and seconds.

### 3. Defining the Planck Function

```python
def planck_spectral_energy_density(wavelength_m, temperature_k):
    exponent = (
        PLANCK_CONSTANT
        * SPEED_OF_LIGHT
        / (wavelength_m * BOLTZMANN_CONSTANT * temperature_k)
    )

    denominator = np.expm1(exponent)

    numerator = 8 * np.pi * PLANCK_CONSTANT * SPEED_OF_LIGHT
    return (numerator / wavelength_m**5) / denominator
```

This function takes:

- wavelength in meters
- temperature in kelvin

It returns the spectral energy density calculated from Planck's radiation law.

The expression `np.expm1(exponent)` is used because it calculates:

```text
exp(exponent) - 1
```

more accurately than manually writing:

```python
np.exp(exponent) - 1
```

This helps reduce numerical error.

### 4. Creating the Wavelength Range

```python
wavelength_nm = np.linspace(100, 3000, 2000)
wavelength_m = wavelength_nm * 1e-9
```

The assignment asked for wavelengths from 100 nm to 3000 nm.

However, the Planck equation must be calculated in meters, so the wavelength
values are converted:

```text
1 nm = 10^-9 m
```

That is why the code multiplies by `1e-9`.

### 5. Plotting the Three Temperatures

```python
temperatures_k = [3000, 4000, 5000]

for temperature_k in temperatures_k:
    u_lambda = planck_spectral_energy_density(wavelength_m, temperature_k)
    plt.plot(wavelength_nm, u_lambda, linewidth=2, label=f"{temperature_k} K")
```

This loop calculates and plots one curve for each temperature. All three curves
are placed on the same graph.

### 6. Adding Graph Details

```python
plt.title("Planck Spectral Energy Density vs Wavelength")
plt.xlabel("Wavelength, lambda (nm)")
plt.ylabel("Spectral energy density, u(lambda, T) (J m^-4)")
plt.legend()
plt.grid(True, alpha=0.35)
plt.tight_layout()
```

These lines make the graph readable by adding:

- title

## What the Graph Shows

The graph shows how spectral energy density changes with wavelength for three
different temperatures.

The main observations are:

- At higher temperatures, the peak spectral energy density becomes much larger.
- At higher temperatures, the peak moves toward shorter wavelengths.
- The 5000 K curve has the highest peak.
- The 4000 K curve is lower than the 5000 K curve but higher than the 3000 K curve.
- The 3000 K curve has the lowest peak and peaks at a longer wavelength.

This behavior agrees with blackbody radiation theory. As temperature increases,
a body emits more radiation overall and emits more strongly at shorter
wavelengths.

This also agrees with Wien's displacement law, which says that the wavelength
of maximum emission decreases as temperature increases.

## Common Issues and Fixes

### Issue: Red lines under `numpy` or `matplotlib` in VS Code

This usually means VS Code is using the wrong Python interpreter.

Fix:

1. Open VS Code.
2. Press `Cmd + Shift + P` on macOS or `Ctrl + Shift + P` on Windows/Linux.
3. Search for `Python: Select Interpreter`.
4. Choose the interpreter inside the project:

```text
.venv/bin/python
```

On Windows, choose:

```text
.venv\Scripts\python.exe
```

Then reload VS Code.

### Issue: pip upgrade warning

If the terminal shows a message saying pip is old, it is only a warning. It is
not an error and the project can still run.

### Issue: Browser says "Not Secure"

This is normal for a local development server using HTTP.

The address `http://localhost:8000/` is only running on the student's own
computer. It does not mean the project is broken.

### Issue: `GET /favicon.ico 404`

This is also normal. The browser is asking for a tab icon file, but the project
does not need one.
